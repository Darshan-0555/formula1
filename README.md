# formula1
**F1 Racing Data Analysis** is a PostgreSQL-based project analyzing Formula 1 drivers, constructors, races, circuits, championships, and performance. It explores race wins, podiums, championships, pole positions, circuit performance, and historical F1 trends using advanced SQL queries.
# F1 Racing Data Analysis

## Project Overview

This project analyzes Formula 1 racing data using PostgreSQL to explore drivers, constructors, races, circuits, championships, and race performance. The analysis uses SQL queries to answer business and analytical questions related to F1 history and performance.

## Analysis

The project covers driver and constructor statistics, race counts by year, championship winners, race wins, podium finishes, pole positions, circuit performance, sprint winners, 2022 season analysis, driver participation, and other historical F1 insights.

## SQL Concepts Used

The project uses SELECT statements, filtering, aggregate functions, GROUP BY, HAVING, JOINs, subqueries, CTEs, CASE statements, window functions, ranking, date functions, and conditional logic.

## Tools Used

PostgreSQL, SQL, and relational F1 datasets.
